## NEXS-1365 - [Multi-Shop] 3PL Failed / Expired 处理机制

创建时间: 27/Apr/26  
更新时间: 28/Apr/26  
状态: To Do  
项目: Nexus  
类型: Story  
优先级: Major  
报告人: Candy Deng  
负责人: Candy Deng  
Epic: CNY LoC - FundPark & CN Trustee

### 描述

作为 Express Finance，我希望处理 3PL Failed / Expired 场景，以便向用户提供相关指引。

### 前置条件

1. 3PL Failed / Expired 处理机制应适用于 FP USD / CNY LoC / DMF 的 Multi-Shop 场景。

### 备注

原文备注: 上面的流程图中，3PL Failed 的场景也应该需要 3PL 重新授权按钮。

### 验收标准

#### AC1 - [DMF & FP USD & CNY LoC] 3PL Not Authorised + Manual Offer Creation Success + Manual Offer Created Within 7 Days

条件: Current Date - Manual Offer Creation Date <= 7 days

Given 卖家位于 Shop Management Page  
When 卖家拥有 US shops  
And 3PL Not Authorised  
And Manual Offer Creation was Success  
And Manual Offer Created Within 7 Days，即 Current Date - Manual Offer Creation Date <= 7 days  
Then 系统展示:

- 3PL column = To be authorise
- 3PL to be authorised reminder message
- skip this store link
- 3PL to be authorised button

#### AC2a - [DMF & FP USD & CNY LoC] 3PL Not Authorised + Manual Offer Creation Success + Manual Offer Created Beyond 7 Days

条件: Current Date - Manual Offer Creation Date > 7 days

Given 卖家位于 Shop Management Page  
When 卖家拥有 US shops  
And 3PL Not Authorised  
And Manual Offer Creation was Success  
And Manual Offer Created Beyond 7 Days，即 Current Date - Manual Offer Creation Date > 7 days  
Then 系统展示:

- 3PL column = Expired
- 3PL re-authorise error message
- skip this store link
- 3PL re-authorise button

And 点击 3PL re-authorise button 后，系统应重新触发 manual offer creation  
And 展示 Add store page，并显示:

- 3PL re-authorise error message

#### AC2b - 点击 "Re-authorise" 按钮

Given 3PL Not Authorised + Expired  
When 卖家点击 "Re-authorise" 按钮  
Then 系统应自动触发 manual offer creation

#### AC3 - [DMF & FP USD & CNY LoC] 3PL Not Authorised + Manual Offer Creation Failed + Failed Reason is Offer Existed

Given 卖家位于 Shop Management Page  
When 卖家拥有 US shops  
And 3PL Not Authorised  
And Manual Offer Creation Failed  
And 失败原因为 "An offer already exists for the seller for the same partner product"  
Then 系统展示:

- 3PL column = To be authorise
- 3PL to be authorised reminder message
- skip this store link
- 3PL to be authorised button

备注: 如果某个 DPU offer 不是在系统中手动创建的，并且经过一段时间后该 offer 在 AMZ 中不再可用，同时 3PL 未授权，则卖家应联系 servicing agent，通过 BOSS 创建该 offer。

#### AC4a - [DMF & FP USD & CNY LoC] 3PL Authorised + 3PL Failed

Given 卖家位于 Shop Management Page  
When 卖家拥有 US shops  
And 3PL Authorised  
And 经过一段时间后，3PL 变为 `<Failed>`  
Then 系统展示:

- 3PL column = Failed
- 3PL re-authorise error message
- skip this store link
- 3PL re-authorise button

And 点击 3PL re-authorise button 后，系统应重新触发 manual offer creation  
And 展示 Add store page，并显示:

- 3PL re-authorise error message

备注: 对于 3PL Failed (Shop abnormal) 场景，Re-authorise 不会触发向 AMZ 创建 manual offer。

#### AC5a - [DMF & FP USD & CNY LoC] 3PL Authorised + 3PL Expired

Given 卖家位于 Shop Management Page  
When 卖家拥有 US shops  
And 3PL Authorised  
And 经过一段时间后，3PL 变为 `<Expired>`  
Then 系统展示:

- 3PL column = Expired
- 3PL re-authorise error message
- skip this store link
- 3PL re-authorise button

And 点击 3PL re-authorise button 后，系统应重新触发 manual offer creation  
And 展示 Add store page，并显示:

- 3PL re-authorise error message

#### AC5b - 点击 "Re-authorise" 按钮

Given 3PL Authorised + 3PL Expired  
When 卖家点击 "Re-authorise" 按钮  
Then 系统应自动触发 manual offer creation

#### AC6 - 返回带 Mission Center 的 Offer Landing Page，Credit Assessment 未开始

Given Credit Assessment 尚未开始  
When 3PL 为 `<Expired>` 或 `<Failed>`  
And 卖家返回 Offer Landing page 并查看 Mission Center  
Then 系统展示 `<Add store is not completed. Action required>`  
And 卖家点击 Action required 后，应展示 Shop Management Page

#### AC7 - 返回带 Mission Center 的 Offer Landing Page，Credit Assessment 已开始

Given Credit Assessment 已开始，即用户已点击 start credit assessment button，但系统尚未将店铺发送给贷款方  
When 3PL 为 `<Expired>` 或 `<Failed>`  
And 卖家返回 Offer Landing page 并查看 Mission Center  
Then 系统展示 `<Credit assessment paused. Action required>`  
And 卖家点击 Action required 后，应展示 Shop Management Page
