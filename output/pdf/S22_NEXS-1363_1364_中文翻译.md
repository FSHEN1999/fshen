## NEXS-1364 - [FP USD LoC] 护照居住地址采集

创建时间: 22/Apr/26  
更新时间: 22/Apr/26  
状态: To Do  
项目: Nexus  
类型: Story  
优先级: Major  
报告人: Candy Deng  
负责人: Candy Deng  
Epic: Line of Credit (LoC) - HK USD - Online Loan Application

### 描述

作为 Data Processing Unit (DPU)，我希望为 FP USD LoC 采集护照对应的居住地址，以便将该数据发送给贷款方，用于贷款申请审批。

### 前置条件

1. CNY LoC 已在 NEXS-1175 和 NEXS-1177 中新增 `<Residential Address>`，现在扩展到 FP USD LoC。
2. 用户已在 T1、T2、T3 首次申请旅程中提交 Business Information Page。
3. 用户已在 Increase Limit Journey 中提交 Business Information Page，且授信审批额度大于 500k 美元。

### 验收标准

#### AC1 C1 T1 / T2 / T3 首次申请旅程 - ID Document Type

Given `<Passport>` 已新增到 `<ID Document Type>`  
When 用户在 Personal information page 中，为每一位 All directors / 持股比例大于等于 25% 的 UBO 选择 `<Passport>`  
Then Residential Address 应展示，且为必填项

#### AC2 Increase Limit Journey (underwritten limit > $500k) - Residential Address

Given `<Passport>` 已新增到 `<ID Document Type>`  
When 用户在 Personal information page 中，被要求为每一位 Director / 持股比例大于等于 25% 的 UBO 的配偶选择 `<ID Document Type>`  
Then Residential Address 应展示，且为必填项

#### AC3 将 Residential Address 发送给贷款方

Given 用户已在 AC1 和 AC2 中输入护照对应的 Residential Address  
When 申请发送给贷款方  
Then Residential Address 应发送给贷款方

### 以下 AC 沿用已有实现

#### AC4 Residential Address 格式与长度

| 字段 | 数据类型 / 格式 | 字段长度 |
| --- | --- | --- |
| Country/Region | 国家/地区，单选，参考 Nationality 列表 | N/A |
| Address Line 1 | 自由文本 | 100 |
| Address Line 2 (Optional) | 自由文本 | 100 |
| City (Optional) | 自由文本 | 50 |
| Postal Code (Optional) | 自由文本 | 20 |

#### AC5 未填写 Residential Address 提交

Given Residential Address 为必填项  
When 用户尝试提交页面  
Then 用户应收到错误提示 `<This field can't be left blank>`  
And 空字段输入框应高亮显示  
And 页面顶部对应个人应标记 `<the section is not yet completed>`，并带有超链接  
And 用户点击该超链接后，应能直接跳转到对应个人的具体区块

## NEXS-1363 - [FP USD LoC] ID Document Type 扩展为支持上传护照

创建时间: 22/Apr/26  
更新时间: 22/Apr/26  
状态: To Do  
项目: Nexus  
类型: Story  
优先级: Major  
报告人: Candy Deng  
负责人: Candy Deng  
Epic: Line of Credit (LoC) - HK USD - Online Loan Application

### 描述

作为 Data Processing Unit (DPU)，我希望扩展 `<ID Document Type>`，使其支持为 FP USD LoC 上传 `<Passport>`，以便将相关文件发送给贷款方，用于贷款申请审批。

### 前置条件

1. CNY LoC 已在 NEXS-1175 和 NEXS-1176 中新增 `<Passport>`，现在扩展到 FP USD LoC。
2. 用户已在 T1、T2、T3 首次申请旅程中提交 Business Information Page。
3. 用户已在 Increase Limit Journey 中提交 Business Information Page，且授信审批额度大于 500k 美元。

### 验收标准

#### AC1a T1 / T2 / T3 首次申请旅程 - ID Document Type

Given 用户被要求在 Personal information page 中，为每一位 All directors / 持股比例大于等于 25% 的 UBO 选择 `<ID Document Type>`  
When 用户查看 `<ID document type>` 区域  
Then 用户应看到 `<Passport>` 被新增到现有证件类型中，现有类型包括 `<PRC Resident Identity Card>`、`<Hong Kong Identity Card>`、`<Mainland Travel Permit for Hong Kong and Macau Residents>`

#### AC1b T1 / T2 / T3 首次申请旅程 - 文案更新

Given 用户位于 Personal information page  
When 用户位于上传区域  
Then 系统应提示用户上传的身份证明文件需与其香港公司的 NNC1 或 NAR1 保持一致

#### AC2 Increase Limit Journey (underwritten limit > $500k) - ID Document Type

Given 用户被要求在 Personal information page 中，为每一位 Director / 持股比例大于等于 25% 的 UBO 的配偶选择 `<ID Document Type>`  
When 用户查看 `<ID document type>` 区域  
Then 用户应看到 `<Passport>` 被新增到现有证件类型中，现有类型包括 `<PRC Resident Identity Card>`、`<Hong Kong Identity Card>`、`<Mainland Travel Permit for Hong Kong and Macau Residents>`

#### AC3 将 Passport 发送给贷款方

Given 用户已在 AC1 和 AC2 中上传 Passport  
When 申请发送给贷款方  
Then Passport 应发送给贷款方

### 以下 AC 沿用 CNY LoC 中 Passport 的已有实现

#### AC4 上传 Passport

Given `<Passport>` 已新增到 `<ID Document Type>`  
When 用户选择 `<Passport>`  
Then 系统应提示用户上传 `<Passport Photo Page>`

#### AC5 为 `<Passport Photo Page>` 上传一个文件

Given 用户点击 `<browser to select>` 按钮  
When 用户为 `<Passport Photo Page>` 选择一个文件  
Then 用户应能够成功将该文件上传到平台

#### AC6 为 `<Passport Photo Page>` 上传多个文件

Given 用户点击 `<browser to select>` 按钮  
When 用户为 `<Passport Photo Page>` 选择多个文件  
Then 用户应看到提示信息，说明只允许上传一个文件

#### AC7 拖拽上传一个 `<Passport Photo Page>` 文件

Given 用户位于上传区域  
When 用户将一个文件拖拽到 `<Passport Photo Page>` 的上传区域 / 拖放区域  
Then 用户应能够成功将该文件上传到平台

#### AC8 拖拽上传多个 `<Passport Photo Page>` 文件

Given 用户位于上传区域  
When 用户将多个文件拖拽到 `<Passport Photo Page>` 的上传区域 / 拖放区域  
Then 用户应看到提示信息，说明只允许上传一个文件

#### AC9 `<Passport Photo Page>` 支持的文件格式

Given 用户上传文件  
When 用户打开文件选择窗口  
Then 文件选择窗口中应只显示受支持格式的文件，包括 jpg、png、jpeg、bmp  
And 用户上传其中一种受支持格式的文件  
And 文件应能成功上传

#### AC10 `<Passport Photo Page>` 不支持的文件格式

Given 用户上传文件  
When 文件格式不属于受支持格式，受支持格式包括 jpg、png、jpeg、bmp  
Then 用户应看到提示信息，说明上传文件格式不受支持

#### AC11 可接受的文件大小

Given 用户上传文件  
When 文件大小在给定限制内，即小于等于 10MB  
Then 文件应能成功上传

#### AC12 文件大小超过限制

Given 用户上传文件  
When 文件大小不在给定限制内，即大于 10MB  
Then 用户应看到提示信息，说明上传文件超过 10MB 大小限制

#### AC13 重新上传

Given 用户请求重新上传  
When 用户点击 `<Remove>` 按钮  
Then 上传区域应重新展示给用户  
And 用户上传新文件  
And 用户应能够看到已有文件已被新文件替换

#### AC14 查看已上传文件

Given 用户已上传或重新上传文件  
When 用户点击 `<View>` 按钮  
Then 用户应能够查看已上传文件

#### AC15 未上传 `<Passport Photo Page>` 提交

Given 用户尚未为任何 Legal representative 的配偶 / 持股比例大于等于 25% 的 UBO 上传 `<Passport Photo Page>`  
When 用户点击 `<Next>` 按钮提交页面  
Then 空字段输入框应高亮显示  
And 页面顶部对应个人应标记 `<the section is not yet completed>`，并带有超链接  
And 用户点击该超链接后，应能直接跳转到对应个人的具体区块

#### AC16 上传失败

Given 用户上传文件  
When DPU 因系统错误导致文件上传失败  
Then DPU 应向用户展示错误提示，说明 `An error occurred in the upload. Please try again`
