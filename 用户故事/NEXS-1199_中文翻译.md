## 验收标准

### AC1: 申请被拒绝时的Offer落地页

**前提条件**: Offer被FundPark拒绝（贷方拒绝或OWS拒绝）  
**当**: 用户浏览Offer落地页时  
**那么**: 用户将被引导至贷方拒绝页面

---

### 三种申请拒绝的用户旅程

#### AC 2.1: [70k-1.5M] 旅程 - 70K贷款申请

**前提条件**: 用户已提交70k即时资金申请  
**当**: 用户已输入所有提款信息并到达待评估页面（参考NEXS-1198）  
**并且**: FundPark拒绝了申请  
**那么**: 用户将被引导至贷方拒绝页面

#### AC 2.2: [70k-1.5M] 旅程 - 选择最高1.5M贷款申请

**前提条件**: 用户在offer选择页面选择最高CNY 1.5M的贷款offer  
**并且**: 用户到达待评估页面等待信用评估结果（参考NEXS-1198）  
**当**: FundPark拒绝申请  
**那么**: 用户将被引导至贷方拒绝页面

#### AC 2.3: [1.5M-10M] 旅程

**前提条件**: 用户已在"业务信息"页面和"关联方信息"页面输入所有信息  
**并且**: 用户到达待评估页面等待信用评估结果（参考NEXS-1198）  
**当**: FundPark拒绝申请  
**那么**: 用户将被引导至贷方拒绝页面

---

### 贷方拒绝场景

#### AC3: 贷方拒绝 - 欺诈拒绝旅程

**前提条件**: 用户已提交贷款申请  
**并且**: FundPark因检测到欺诈而拒绝offer  
**当**: 用户浏览Offer落地页  
**那么**: 用户将被引导至贷方拒绝页面

#### AC3.2: 贷方拒绝 - 欺诈拒绝逻辑

**前提条件**: 卖家向FundPark提交申请  
**当**: FundPark拒绝申请，拒绝原因包含关键词"Fraud"  
**并且**: 当前时间 - 拒绝时间 > 24小时  
**并且**: 没有其他活跃申请  
**那么**: DPU将标记申请为已拒绝，并通知Amazon拒绝状态，同时：
- Application Rejection Category = KYC
- Application Rejection Code = Fraud

**执行时间**: 每天23:30:00定时任务

#### AC4: 贷方拒绝 - 非欺诈拒绝逻辑

**前提条件**: 卖家向FundPark提交申请  
**并且**: 当前时间 - 拒绝时间 > 24小时  
**并且**: 没有其他活跃申请  
**当**: FundPark拒绝申请，拒绝原因**不包含**关键词"Fraud"  
**那么**: DPU将标记申请为已拒绝，并通知Amazon拒绝状态，同时：
- Application Rejection Category = POLICY
- Application Rejection Code = FAILED_APPLICATION_CRITERIA

**执行时间**: 每天23:30:00定时任务

---

### OWS拒绝场景

#### AC 5.1: 制裁命中且BOSS用户拒绝贷款申请

**前提条件**: OWS RTS筛查命中"MATCH"结果  
**并且**: BOSS用户在BOSS的制裁筛查页面确认拒绝申请  
**当**: 用户浏览Offer落地页  
**那么**: 用户将被引导至贷方拒绝页面

**注**: 已在S16的NEXS-1148 AC5中实现

#### AC5.2: OWS拒绝逻辑

**前提条件**: OWS RTS筛查命中"MATCH"结果  
**并且**: BOSS用户在BOSS的制裁筛查页面确认拒绝申请  
**那么**: DPU将标记申请为已拒绝，并通知Amazon拒绝状态，同时：
- Application Rejection Category = KYC
- Application Rejection Code = SANCTION_AND_POLITICAL_PERSON_CHECK_FAILED

**执行时间**: 每天23:30:00定时任务

---

### 数据删除

#### AC6: Offer被拒绝时的数据删除

**前提条件**: 收到贷方的拒绝状态  
**当**: DPU更新拒绝状态至Amazon  
**那么**: 执行以下操作：
1. 验证状态，如果无法检索数据
2. 将3P授权Token标记为已过期
3. **仅删除**3PL卖家绩效数据
4. 重置3PL关联商户的额度值，包括指示性额度（待确认）

## 技术实现要点

### 拒绝通知时机
- 所有拒绝逻辑通过定时任务执行（每天23:30:00）
- 拒绝后需等待24小时才触发通知（给用户缓冲时间）

### 拒绝分类
1. **欺诈拒绝**: 
   - Category: KYC
   - Code: Fraud
   
2. **政策拒绝**: 
   - Category: POLICY
   - Code: FAILED_APPLICATION_CRITERIA
   
3. **制裁拒绝**: 
   - Category: KYC
   - Code: SANCTION_AND_POLITICAL_PERSON_CHECK_FAILED

### 数据清理范围
- ✅ 删除: 3PL卖家绩效数据
- ✅ 过期: 3P授权Token
- ✅ 重置: 3PL商户额度值
- ❌ 保留: 其他用户基础数据（符合GDPR要求）

2. FundPark返回拒绝，原因不包含"Fraud"

4. 验证用户看到贷方拒绝页面
5. 验证Amazon收到正确的拒绝分类和代码
